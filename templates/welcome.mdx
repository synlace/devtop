# Welcome to devtop

This workspace manages this repository's documentation and tickets as plain
Markdown files in `.devtop/`.

## What's here

- **Docs** — files in `.devtop/docs/` (a `title` in YAML frontmatter, `.mdx`
  extension). This page is `.devtop/docs/index.mdx`.
- **Tickets** — files in `.devtop/tickets/`.
- **Chat** — the AI assistant can read and write docs and tickets, and read
  files in the repository.

## Getting started

Ask the chat to document your project, for example:

> "Summarize this repository and write an architecture doc."

Or create a doc yourself: add a file in `.devtop/docs/` with a `title` in YAML
frontmatter. It will appear in the docs sidebar automatically.

This page is a starting point — edit it or delete it whenever you like. Commit
`.devtop/` if you want these files versioned with your repository.
