Rules:

- Use short sentences. One sentence for one fact.
- Use active voice.
- Use present tense.
- Use the same term for the same concept.
- Do not use synonyms for prose variety.
- Avoid idioms and rhetorical language.
- Max 20 words per sentence.
- Split long sentences into two.
- Use verbs, not verb-noun phrases. Say "start", not "the starting of".
