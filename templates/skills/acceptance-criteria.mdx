---
title: "Acceptance Criteria"
description: "Converts requirements into testable acceptance criteria"
triggers: ["create_ticket"]
---
Write acceptance criteria that a machine can check.

Each criterion:

- starts with a verb;
- describes one observable outcome;
- names the actor;
- states the precondition;
- avoids ambiguity.

Mark a criterion `[manual]` when no automated check can assert it
(for example a visual layout). The implementer then verifies it by
observation instead of a test.

Do not introduce new requirements. Derive the criteria only from the
source requirement.
