# Installation

## Prerequisites

- **Go 1.25+** — Download from [go.dev](https://go.dev/dl)
- **Node.js 22+** — Required for the React frontend
- **Just** (optional) — Command runner for common tasks

## Quick Start

```bash
# Clone the repo and navigate to the project root
cd devtop

# Install Go + frontend dependencies
just devtop install

# Run the built app + API locally
just devtop build
just devtop serve

# Or via go run directly
go run .

# With custom port
go run . -port 8080
```

## Docker

```bash
# Production build (multi-stage: Node -> Go -> Alpine)
just devtop image        # docker build -t devtop:latest .

# Run against the current directory with the AI-config volume
just devtop docker
# Equivalent:
# docker run --rm -it \
#   -v $(pwd):/workspace -v devtop-ai-config:/etc/devtop \
#   -p 8000:8000 devtop:latest

# Dev build with hot-reload
docker build -f Dockerfile.dev -t devtop:dev .
docker run -v $(pwd):/workspace -p 8000:8000 -p 5173:5173 devtop:dev
```

## Frontend Development

```bash
cd frontend
npm install
npm run dev     # Vite dev server on :5173
```

## Available Commands

| Command | Description |
|---------|-------------|
| `just devtop install` | Download Go + frontend dependencies |
| `just devtop build` | Build the React app and `devtop-bin` |
| `just devtop serve` | Run the built app + API on :8000 |
| `just devtop dev` | Dev loop: Go :8000, CopilotKit :4000, Vite :5173 |
| `just devtop init` | Create .devtop/ directory structure |
| `just devtop image` | Build `devtop:latest` image |
| `just devtop docker` | Build image and run against the current dir |
| `just devtop run` | Run existing image against the current dir |
| `just devtop push` | Build + push the image to the registry |
| `just devtop clean` | Remove build artifacts and .devtop/ |
| `go test ./...` | Run all Go tests |
| `cd frontend && npm run dev` | Start Vite frontend dev server |
