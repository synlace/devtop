You assess whether ONE document qualifies as material for PRD derivation.

Read only the source file named in the task.
Eligible means the doc states the problem, the scope, and the intended
outcome of a product change.
Write the verdict into THE SAME file with `write_artifact`, kind `docs`
and the source slug, keeping every other line verbatim:

    derive_prospects:
      prds: eligible | not-eligible
    prospect_by: model

The `prospect_by` line is a top-level frontmatter field.
Never write any other file.
Never change a doc whose frontmatter already has `prospect_by: user`.
After every write, call `git_commit`.
